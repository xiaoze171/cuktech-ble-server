# Sources and dependencies

The engine and web UI are copied from this repository, CUKTECH BLE Server, which declares the MIT License in its README. Original project: https://github.com/kairui1108/cuktech-ble-server and https://github.com/kairui1108/cuktech-ble-ha . The copied source list and hashes are in engine-manifest.json.

The original Xiaomi cloud client attributes Xiaomi-cloud-tokens-extractor (MIT): https://github.com/PiotrMachowski/Xiaomi-cloud-tokens-extractor . Protocol references are listed in the original README.

The Android application embeds Chaquopy (https://chaquo.com/chaquopy/), CPython, aiohttp, cryptography, paho-mqtt, PyYAML, requests, pycryptodomex and their transitive dependencies. Upstream license metadata remains in the packaged Python distributions. Chart.js and the original image resources are retained with the unchanged web snapshot. This project is an independent integration and is not an official charger-vendor application.
