# 独立 Android 版设计

用户要求：功能保持一样，UI 也一致，手机端单独实现并交付 APK。用户已明确选择手机独立运行版本。

## 架构

独立 `android/` 工程，应用 ID `com.cuktech.mobile`。APK 内置原项目全部 Web 页面、图片、语言包和业务引擎。Chaquopy 在手机进程中运行 Python；Android 原生 BluetoothGatt 替代桌面 bleak 蓝牙传输层，保留已经存在的 MiOT 认证、协议解析、充电统计算法。页面通过仅绑定 `127.0.0.1` 的内部 HTTP 服务访问业务逻辑，不连接电脑，不要求额外服务器。

默认打开现有 `phone.html`，保留配置页面及其它页面。使用 Android 前台服务维持蓝牙、MQTT、巴法云和记录任务；用户可从通知明确停止。Android 7.0+，arm64-v8a 与 x86_64，target/compile SDK 35。

## 功能对应

- BLE：扫描、权限申请、GATT 连接、MTU 协商、通知、MiOT 认证、重连、质量指标。
- 控制：四端口开关、场景、协议开关、倒计时、设备设置。
- 显示：原有手机界面、桌面界面、曲线、主题、国际化。
- 数据：应用私有目录中的配置与 SQLite，历史、会话、电量、CSV 导出。
- 云：小米扫码获取设备凭据、MQTT、巴法云及语音控制；这些在线服务仍需要网络及对应账户。
- 生命周期：配置保存后在应用进程内重启业务服务，禁止使用桌面的 os.execv；退出页面保留前台服务，通知停止释放连接。

## Android 边界

`GattBridge(Context)` 提供阻塞但有超时的扫描、连接、读写、通知开关；Python 使用 `asyncio.to_thread` 调用。通知通过有界队列轮询返回 JSON，Python 在 asyncio 线程派发回调，避免 Android 回调线程操作 asyncio.Queue。一个时刻只允许一个 GATT 操作；断开时唤醒正在等待的操作，清理过期通知。

手机端 Python 副本在 `android/app/src/main/python`，Web 副本位于其 `web/`。副本清单记录原始 SHA-256，便于核对 UI 一致性；桌面原文件不改。配置默认关闭尚未配置的云连接，空 MAC/token 不扫描。Android 独立层修正空数据库路径、无效配置保存和平台重启方式。

## 验证与交付

运行 Android 适配层单元/集成测试、复用业务与前端测试、构建 APK、检查签名与清单，并通过模拟器（若环境可用）验证安装启动和页面。真实充电器认证及控制必须用 Android 真机和设备凭据验证；没有硬件证据时不得声称实连成功。输出独立源码、构建说明和签名 APK；保留本地签名密钥供后续升级，不提交密钥。
