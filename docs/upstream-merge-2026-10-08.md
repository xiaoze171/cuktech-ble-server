## 审查发现及处理

1. **取消自动关断后旧命令仍可能断电。** 自动命令增加来源和每端口代次；模式/限额修改、新会话和断连使旧命令失效。在读取状态前及读取后、提交 SET 前复核策略。手动开关保持可用。
2. **设备回显拒绝关断，本地仍误报成功。** 状态、接口结果和一次性策略消费改为依据设备有效掩码；GET 已确认关闭、无需 SET 时也更新缓存和会话。充满即停依据 PIID16 的关断位确认。
3. **Windows 保存配置后服务退出、启动器不重启。** `start.bat` 显式声明重启能力，仅对退出码 75 重新启动；普通错误不循环重启，未托管的 Python 启动保留原有 execv 路径。

保留本地推送即时处理、断连唤醒、Android 快速连接与蓝牙恢复提示、SSE 长连接、手机卡片排序/曲线和应用内更新。统一变更资源的缓存版本，避免新旧脚本混用。
